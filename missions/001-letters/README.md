# MISSION 001 v0.1 · Дело о потерянных письмах

Открой корневой `index.html`, начни расследование и выбери Дом воспоминаний. На iPhone открой ту же статическую страницу в Safari. Карточка дела ведёт к открытке и трём вопросам. После ответов открой письмо, увеличь снимок при необходимости и сохрани его в архиве. На карте появится фрагмент «ТЫ» и откроется Фотостудия.

`mission.js` управляет вопросами и просмотром снимков, `mission.css` оформляет их в существующем диалоге оболочки. Промежуточный шаг хранится под ключом `lovequest.chapter04.letters.v1` или в памяти вкладки при запрете сохранения. Завершение записывает оболочка своим существующим ключом. Повторный просмотр доступен через карточку 001. Если дело ранее завершили через dev mode, для раскрытия снимка всё равно нужно ответить на три вопроса.

Для ручной проверки попробуй неверный ответ и подсказку, выйди на карту после первого ответа, затем продолжи. После сохранения проверь журнал, перезагрузку и повторное открытие письма. На iPhone проверь масштаб, прокрутку увеличенного фото и закрытие окна.

Публикуемый набор для оболочки и миссии 001:

- `index.html`, `css/main.css`, `js/main.js`
- `missions/001-letters/mission.css`, `missions/001-letters/mission.js`
- `assets/mission-001/letter-mystery.jpg`, `assets/mission-001/letter-revealed.jpg`

Из загрузки исключи `private-source/` и `assets/references/`. Игровые JPEG сохраняют исходные размеры 1183 × 887 и маски на рукописном адресе и индексе. Из копий удалены EXIF и другие дополнительные метаданные. Печатные сведения о заведении остаются частью открытки и служат уликой.

Раскрытая игровая копия содержит утверждённые имя получателя и рукописное послание. В игре снимок появляется после трёх ответов. При размещении на статическом сайте сам файл будет доступен по прямому адресу.
